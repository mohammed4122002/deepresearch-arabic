# DeepResearch Arabic

مساعد بحث عربي تجريبي يجمع بين البحث على الويب عبر [Tavily](https://tavily.com/) وتوليد النصوص بنموذج محلي عبر [Ollama](https://ollama.com/). يجهّز نتائج البحث كمصادر مرقّمة، ثم يطلب من النموذج كتابة تقرير عربي يستند إليها.

> **حالة المشروع:** المشروع حاليًا نموذج أولي يعمل من سطر الأوامر، وليس تطبيق ويب. قد لا يلتزم النموذج دائمًا بالإحالات؛ عند تعذّر التحقق منها بعد محاولتين، يعرض البرنامج مقتطفات المصادر بدلًا من تقديم تقرير تحليلي غير موثّق.

## الميزات الحالية

- البحث في الويب باستخدام Tavily.
- تنظيم نتائج البحث إلى عنوان ورابط ومقتطف ودرجة صلة.
- إرسال المصادر إلى نموذج محلي عبر Ollama لتوليد تقرير عربي.
- التحقق من أن أرقام الإحالات المذكورة تطابق مصادر موجودة.
- إنشاء قائمة المصادر من روابط نتائج البحث الأصلية.
- إعادة محاولة التوليد مرة واحدة، ثم عرض مقتطفات المصادر مع تحذير عند فشل الإحالات.
- اختبارات وحدوية لا تحتاج اتصالًا بالإنترنت أو تشغيل Ollama.

## كيف يعمل؟

1. يرسل البرنامج سؤال البحث إلى Tavily.
2. يجهز النتائج التي تحتوي روابط ويعطيها أرقامًا مثل `[1]` و`[2]`.
3. يرسل السؤال ومقتطفات المصادر إلى نموذج Ollama المحدد في الإعدادات.
4. يتحقق من وجود إحالات ومن أن أرقامها تخص مصادر متاحة.
5. يعرض التقرير والمراجع عند نجاح التحقق، أو مقتطفات المصادر مع تحذير إذا لم يلتزم النموذج.

التحقق الحالي يراجع **وجود أرقام المصادر فقط**؛ ولا يثبت أن المصدر يدعم الادعاء بجواره أو أن محتوى الصفحة صحيح وحديث. راجع المصادر بنفسك قبل الاعتماد على النتائج.

## المتطلبات

- Python 3.10 أو أحدث.
- حساب ومفتاح API من Tavily.
- Ollama مثبت ويعمل محليًا.
- نموذج `qwen2.5:1.5b` منزّل في Ollama، أو نموذج آخر تحدده في `LLM_MODEL`.

## الإعداد

### 1. استنسخ المشروع وأنشئ بيئة افتراضية

```powershell
git clone https://github.com/mohammed4122002/deepresearch-arabic.git
cd deepresearch-arabic
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

على macOS أو Linux:

```bash
git clone https://github.com/mohammed4122002/deepresearch-arabic.git
cd deepresearch-arabic
python3 -m venv .venv
source .venv/bin/activate
```

### 2. ثبّت الحزم

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt ollama
```

تُثبّت حزمة `ollama` صراحةً لأن الكود يستخدمها حاليًا، لكنها غير مدرجة بعد في `requirements.txt`.

### 3. أعدّ متغيرات البيئة

انسخ `.env.example` إلى ملف باسم `.env` في جذر المشروع، ثم استبدل `replace_me` بمفتاح Tavily:

```env
LLM_MODEL=qwen2.5:1.5b
SEARCH_API_KEY=ضع_مفتاح_Tavily_هنا
```

في PowerShell:

```powershell
Copy-Item .env.example .env
```

لا تشارك ملف `.env` ولا ترفع مفاتيح API إلى GitHub.

### 4. جهّز نموذج Ollama

نزّل النموذج المحدد في `.env`:

```bash
ollama pull qwen2.5:1.5b
```

تأكد من أن Ollama يعمل قبل تشغيل تجربة إنشاء التقرير. إذا اخترت نموذجًا مختلفًا، حدّث قيمة `LLM_MODEL` ونزّل ذلك النموذج.

## التشغيل

من مجلد المشروع، شغّل تجربة البحث وإنشاء التقرير:

```bash
python -m tests.test_report
```

تستخدم هذه التجربة سؤالًا ثابتًا مع Tavily وOllama، لذلك تتطلب مفتاح Tavily واتصالًا بالخدمة وتشغيل Ollama محليًا.

يمكن تجربة البحث وحده تفاعليًا:

```bash
python -m research.search
```

## الاختبارات

تشغيل الاختبارات الوحدوية الخاصة بالتحقق من الإحالات:

```bash
python -m unittest discover -s tests -p "test_report_unit.py" -v
```

هذه الاختبارات تحاكي استجابة النموذج، ولا تحتاج مفتاح Tavily أو اتصال Ollama.

أما تجربة اتصال Ollama المباشرة فتُشغّل هكذا:

```bash
python -m tests.test_ollama
```

وتتطلب تشغيل Ollama ووجود النموذج المحدد.

## هيكل المشروع

```text
.
├── app.py
├── config.py
├── research/
│   ├── report.py
│   └── search.py
├── schemas/
├── tests/
│   ├── test_ollama.py
│   ├── test_report.py
│   └── test_report_unit.py
├── .env.example
└── requirements.txt
```

- `config.py`: يحمّل إعدادات النموذج ومفتاح البحث من البيئة.
- `research/search.py`: يبحث عبر Tavily ويعيد نتائج موحّدة.
- `research/report.py`: يولّد التقرير، يتحقق من الإحالات، ويجهّز المصادر أو البديل الآمن.
- `tests/test_report_unit.py`: اختبارات وحدوية من دون خدمات خارجية.
- `tests/test_report.py`: تجربة تكاملية للبحث ثم توليد التقرير.
- `tests/test_ollama.py`: تجربة اتصال مباشرة بالنموذج.
- `app.py`: محجوز حاليًا؛ واجهة التطبيق لم تُنفّذ بعد.

## الحدود المعروفة

- المشروع حاليًا أداة تجريبية عبر سطر الأوامر، ولا يحتوي واجهة ويب.
- النموذج قد ينتج إجابة بلا إحالات صالحة؛ عندها يعرض البرنامج مقتطفات المصادر بدل تقرير مولّد.
- صحة الإحالات الرقمية لا تعني أن الادعاءات مدعومة فعلًا بالمصادر.
- البرنامج يعتمد على مقتطفات البحث، ولا يتحقق بصورة مستقلة من صفحات الويب أو تاريخها.
- استخدام Tavily يخضع لشروط الخدمة والحصص أو الأسعار الخاصة بحسابك.
